    PRYWATNA PRACOWNIA

    Metodyka pod kontrolą

    Stałe przypadki kontrolne pomagają zauważyć zmianę pierwotnych obliczeń.

    Rok nie jest redukowany do jednej cyfry.

    1974 → 1 + 9 + 7 + 4 = 21. Ponieważ 21 ≤ 22, osobowość pozostaje 21. Dopiero dla Talentu: 2 + 1 = 3.

    Przypadki kontrolne

    Wyniki w kolejności: Dar / Karma / Osobowość / Talent / Węzeł / Tikkun. Kliknij przykład, aby prześledzić go w formularzu.

    Kontrola obu metod posagu

    Wibracja narodzin / odejścia / różnica (metoda 1) / rok osobisty / dzień i miesiąc odejścia / wynik metody 2. Brak warunku 9–9 oznacza brak wyniku zero w metodzie 2.

    Profil urodzenia zachowuje 22 wartości. Obie metody posagu są obliczane osobno; wiek zmienia język interpretacji, a nie liczby.
